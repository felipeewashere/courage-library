# Courage UI v2

A Roblox UI library built around groupboxes, with the same style of API as Linoria and Obsidian. It ships as one file: `dist/CourageUI.lua`.

## Use

```lua
local Library = loadstring(game:HttpGet("<raw link to dist/CourageUI.lua>"))()
local Window = Library:CreateWindow({ Title = "Courage Hub", Footer = "Game name" })

local Tab = Window:AddTab("Main", "house")              -- Lucide icon name, asset id, or rbxassetid://
local Box = Tab:AddLeftGroupbox("Farming", "zap")

Box:AddToggle("AutoFarm", { Text = "Auto Farm", Default = false, Callback = function(on) end })
    :AddKeyPicker("AutoFarmKey", { Default = "F", SyncToggleState = true })
Box:AddSlider("Delay", { Text = "Farm Delay", Default = 0.5, Min = 0, Max = 2, Rounding = 1, Suffix = "s" })
Box:AddDropdown("Mode", { Text = "Farm Mode", Values = { "Nearest", "Strongest" }, Default = 1 })

print(Library.Toggles.AutoFarm.Value)
Library.Options.Delay:SetValue(1)
```

`Example.lua` shows every element.

## What is in it

| Area | Members |
|---|---|
| Window | `Library:CreateWindow`, `Window:AddTab(name, icon)`, `Window:AddDialog`, `Library:Toggle`, `Library:Unload` |
| Tabs | `AddLeftGroupbox`, `AddRightGroupbox`, `AddLeftTabbox`, `AddRightTabbox`, `AddSubTab` |
| Elements | `AddToggle`, `AddButton` (and `:AddButton` for a second one on the row), `AddLabel`, `AddDivider`, `AddSlider`, `AddDropdown` (single, multi, searchable, player and team lists), `AddInput`, `AddDependencyBox` |
| Addons on a toggle or label | `:AddKeyPicker` (Toggle / Hold / Always), `:AddColorPicker` (with optional transparency) |
| Outside the window | `Library:Notify`, `Library:SetWatermark` / `SetWatermarkVisibility`, `Library:SetKeybindMenuVisible`, tooltips (`Tooltip = "..."` on any element) |
| Themes | `Library.ThemeManager`: 12 built-in themes, custom colours, fonts, saved custom themes |
| Configs | `Library.SaveManager`: create, load, overwrite, delete, autoload |

Tabs named `UI Settings`, `Settings` or `Profile` (or added with `Footer = true`) become the small icons under the sidebar divider.

The menu key is Right Shift. A draggable pill (logo, name, moving sound wave) opens and closes the menu on every device; set `Library.ShowToggleButton = "Mobile"` to keep it to touch devices, or `false` to hide it.

## Build

```
node LibraryV2/build.mjs              bundle src/ + addons/ into dist/CourageUI.lua (minified)
node LibraryV2/build.mjs --readable   keep line breaks, for debugging
node LibraryV2/build.mjs --install    also copy the bundle, Example.lua and assets/ into the Potassium workspace (CourageUI/)
```

Then run `loadstring(readfile("CourageUI/Example.lua"))()` in the executor.

## Layout

```
src/Init.lua        entry: creates the Library table and the screen layers, loads the modules
src/Util.lua        instance creation bound to the theme, tweens, input helpers
src/Theme.lua       schemes and the registry that repaints on a theme change
src/Assets.lua      PNG cache (assets/) and Lucide icons
src/Window.lua      window, sidebar, tabs, sub tabs, search, dialog, open / close
src/Container.lua   groupbox, tabbox, dependency box and the Add* methods
src/Elements/       one file per element
src/Hud.lua         notifications, tooltip, watermark, key bind menu, toggle pill
src/Cat.lua         the header cat
addons/             ThemeManager.lua, SaveManager.lua
assets/             logo and cat frames (assets/cat is generated by tools/make_cat.py)
```

## Before publishing

- `src/Assets.lua` has `BaseUrl` pointing at a repository that does not exist yet. Set it to the raw `assets/` folder of the new repository. Until then images are only found in the executor's `CourageUI/assets/` folder (what `--install` fills).
